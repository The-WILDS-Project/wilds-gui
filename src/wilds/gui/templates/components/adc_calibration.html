A stage's zero point is what it reads when its pair is at the reference position; the pair's angle everywhere else is the stage's reading minus it. Saved in the ADC's calibration values (/config/adc/cal), with who and why. Greyed out when the ADC is not installed. {% endcomment %}
The ADC is not installed, so its calibration is greyed out (Engineering → Configuration → adc → Installed).

The reference of each prism pair to its stage: what the stage reads when the pair is at its reference position. The pair's angle is the stage's reading minus this zero point. Put the pair at its reference (Operations → ADC, set by hand, with tracking off), then press Use the current reading, or type the value.
